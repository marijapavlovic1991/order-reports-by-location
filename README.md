# order-reports-by-location
Dashboard za analizu podataka i profita prema državama i gradovima. Podaci su agregirani po geografskim kategorijama, uz mogućnost filtriranja i poređenja rezultata. Interaktivna mapa omogućava vizuelni pregled raspodjele podataka po državama.
